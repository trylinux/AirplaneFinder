### 3.2 Corrections to the earlier passes, with evidence

1. **Phase 2 section 3f lists "Tobyhanna Army Depot — nothing found" and Phase 3 section 3.8
   parks it as "Phase 2 / restricted". Both are wrong.** The depot maintains a signed outdoor
   memorial display park on Hap Arnold Boulevard with, at minimum, an AH-1S, an F-14, an
   OH-58D, an OH-6A, an OV-1 and an RC-12H, each with its own interpretive marker erected by
   the depot. HMdb catalogued all six on 6 November 2023. Aerial Visuals adds a UH-1C and a
   C-130A with mapped fixes. Recorded above.
2. **Phase 3 excluded C-130A 54-1622 at Wyoming Valley Airport, Forty Fort, as "not on-site".
   Correct — and this pass found where it went: Tobyhanna Army Depot, Aerial Visuals site H,
   41.191647 / -75.437719.** Same airframe, one place, now placed.
3. **Phase 3 excluded the Chambersburg / Guilford Township AH-1 as "an unconfirmed AV NEED HELP
   entry with no serial". It has a serial: 67-15653**, from the Army display-helicopter
   disposition list, which places it with "Guilford Township, Chambersburg PA". 67-15653 checks
   against the FY67 AH-1G block 67-15450/67-15873. It is NOT the same machine as 67-15663, the
   Phillipsburg Cobra that Phase 3 traced to Carlisle — the two serials differ by ten and both
   are valid. Still not recorded here because no location and no dated sighting exist. See
   open question 3.
4. **Two serials in the Army list that look like PA hits are not PA.** 68-15074 AH-1 is at
   Vietnam Veterans Assoc. #142 in **Monroe, MICHIGAN**, not Monroe County PA, and 68-15086 is
   at VFW Post #1470, **Bath, NEW YORK**. Anyone re-running that source will be tempted by both.
5. **Aerial Visuals files "Alexandria, Alexandria Field Airport" under Pennsylvania. Alexandria
   Field is in Pittstown, NEW JERSEY.** Mis-filed row; ignore it.
6. **The Aerial Visuals NAVICP dossier calls BuNo 122811 a "Douglas A-1E Skyraider". Impossible.**
   122811 is an AD-3; the AD-3 was long gone before the 1962 tri-service redesignation that
   created the A-1E from the AD-5. OSM independently names the node "AD-3 Skyraider BuNo 122811".
   Recorded as AD-3.
7. **Serials the earlier passes could not supply for a Phase 1 site.** The Army disposition list
   gives the American Helicopter Museum's Cobra as **AH-1 68-15138** and its Raven as
   **OH-23 62-3769**. Phase 1 recorded that museum with blank tail_numbers. Offered for merge;
   not re-recorded here because the site already exists in Phase 1.

### 3.7 Methods that were tried and failed, so nobody repeats them

- **Overpass regex queries over the full PA bbox** (matching aircraft names against
  `tourism=attraction` / `historic=memorial` / free-text `name`) **time out on the
  private.coffee mirror**, repeatedly, at 290 s. The plain tag queries
  (`historic=aircraft`, `memorial=aircraft`, `memorial:type=aircraft`, `aeroway=aircraft`)
  do complete and returned the 49 objects described above. If someone wants the regex sweep,
  it needs a different mirror or a county-by-county bbox split.
- **HMdb.org blocks curl with a Cloudflare interstitial.** It is reachable through a fetch tool
  that renders. `hmdb.org/results.asp?Search=Place&Town=<town>&State=Pennsylvania` is the useful
  entry point and is how Tobyhanna was found — it lists every marker in a town, aircraft included.
  **This is the highest-yield untapped method left for Pennsylvania** and it can be run town by
  town against the unswept list.
- **FAA name/owner search** (`NameResult`) returns empty for POST field guesses; only
  `NNumbertxt` against `NNumberResult` works. So the Nemacolin collection could not be
  enumerated by owner.
- Generic per-town web searches ("<town> PA jet display", "<town> Pennsylvania VFW helicopter")
  were run for Bethlehem, Easton, Scranton, Wilkes-Barre, Sunbury, Selinsgrove, Lewisburg,
  Meadville, Oil City, Titusville, Warren, Kane, Ridgway, New Castle, Somerset, Bedford,
  Uniontown, Media, Norristown, Chambersburg, Lancaster and Indiana. **Yield: one site**
  (Willow Grove, and that surfaced on an unrelated query). Search engines return museum
  boilerplate for these; the method is close to worthless at this density and should not be
  the next pass's main tool.

### 3.8 Not reached in this pass

- **A street-view / satellite sweep of the 25 single-source Phase 3 coordinates and of the five
  weak-currency airframes here.** This remains the cheapest large win in the state and no tool
  available in this pass could do it.
- **HMdb town-by-town for the unswept counties.** Only Tobyhanna was queried this way, and it
  immediately produced eight airframes. Lancaster, Chester, Delaware, Northampton, Monroe,
  Centre, Crawford, Venango, Fayette, Indiana, Franklin, Lebanon, Berks, Schuylkill, Mercer,
  Lawrence, Greene, Washington and Bedford were NOT queried this way.
- **The PA VFW and American Legion post directories** (vfwpa.org; legionfinder.com, ~207 PA
  posts) paired against imagery — the systematic method Phase 3 identified and nobody has run.
- **Bensalem, Bucks County:** OSM node 13180598800 at 40.0784357 / -74.9236009, tagged
  `historic=aircraft`, no name, no ref. Still unidentified after this pass. Phase 3's open
  question 8 stands.
- County historical societies, fire stations, fairgrounds, vo-tech campuses and roadside
  oddities were not searched systematically anywhere. Only what the four structured sources
  happened to carry was found.
